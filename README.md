## 🛠 Разработка

### [Throne Dual Proxy](https://github.com/lllexalllepexa/Throne-DualProxy-win) &nbsp; [![Release](https://img.shields.io/github/v/release/lllexalllepexa/Throne-DualProxy-win?style=flat-square&label=release&color=00599C)](https://github.com/lllexalllepexa/Throne-DualProxy-win/releases/latest)

Форк Throne (GUI для sing-box) с нативным режимом Dual Proxy: два независимых прокси на разных локальных портах (2080 и 2081), назначение второго прокси в один клик, отдельное определение IP и страны, свой DNS без утечек между прокси. Синхронизирован с актуальной версией upstream.

`C++20` `Qt 6` `sing-box` `Go`

### [Twitch Local SOCKS5 Proxy](https://github.com/lllexalllepexa/twitch-local-socks5-proxy)

Браузерное расширение (Chrome и Firefox, MV3), чтобы стримы на Twitch не висли: на 3 секунды пускает запрос токена через локальный SOCKS5 (Throne), а сам видеопоток идёт напрямую через быстрый CDN.

`JavaScript` `WebExtensions MV3`

### 🎬 Home Media Server (*arr stack)

Автоматизированный домашний медиасервер в Docker: Radarr, Sonarr, Prowlarr и qBittorrent с маршрутизацией трафика через VPN-контейнер, плюс безопасный удалённый доступ для стриминга откуда угодно.

`Docker Compose` `Linux` `Self-Hosting` `Networking`

### [Deadlock Build Randomizer](https://github.com/lllexalllepexa/randomizer777) &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-222222?style=flat-square&logo=githubpages&logoColor=white)](https://lllexalllepexa.github.io/randomizer777/)

Веб-рандомайзер сборок предметов для игры Deadlock.

`HTML5` `CSS3` `JavaScript`
