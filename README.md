- **BI & Дашборды:** Проектирование отчётов для стейкхолдеров — Power BI, Apache Superset, Yandex DataLens, Streamlit, визуализация Plotly & Seaborn.
- **Бизнес-метрики:** Когортный анализ (Retention, Churn), LTV, воронки, сегментация клиентов (RFM), факторный анализ выручки и маржинальности.
- **Продвинутый SQL & Витрины:** Сложные аналитические запросы (оконные функции, рекурсивные CTE), проектирование витрин данных в PostgreSQL, DuckDB, ClickHouse.
- **Прикладная статистика:** Проверка гипотез и A/B тестирование (t-тесты, p-value), регрессионный анализ (OLS), снижение размерности (PCA, scikit-learn).
- **ETL & Автоматизация:** Пайплайны обработки данных и проверки качества (Data Quality) на Python (Pandas), PySpark и Apache Airflow.

### 🚀 Проекты

#### 🌐 [Throne-DualProxy-win](https://github.com/lllexalllepexa/Throne-DualProxy-win)
> Нативный форк Throne (Sing-Box GUI) с поддержкой одновременной работы двух параллельных прокси-серверов на разных портах (2080 и 2081), выбором портов из UI и раздельным определением IP/стран.  
> `C++20` `Qt6` `Sing-Box`

#### 📊 [Global Superstore Analytics](https://github.com/lllexalllepexa/testsomeshi)
> Комплексный дата-пайплайн на 51 000+ транзакций: от сырого CSV до Parquet-хранилища, SQL-витрин (DuckDB / Postgres), Airflow DAG, статистических моделей (OLS, PCA) и дашборда на Streamlit.  
> `Python` `Airflow` `PySpark` `DuckDB` `PostgreSQL` `Streamlit`

#### 🎬 Home Media Server (*arr Stack)
> Полностью автоматизированный домашний медиасервер в Docker: стек Radarr, Sonarr, Prowlarr, qBittorrent (с маршрутизацией трафика через VPN-контейнер) и безопасный удалённый доступ для стриминга из любой точки.  
> `Docker Compose` `Linux` `Self-Hosting` `Networking`

#### 🟣 [Twitch Local SOCKS5 Proxy](https://github.com/lllexalllepexa/twitch-local-socks5-proxy)
> Браузерное расширение (Chrome & Firefox MV3), чтобы стримы на Twitch не висли: на 3 секунды пускает токен через локальный SOCKS5 (Throne), а сам видеопоток идёт напрямую через быстрый CDN.  
> `JavaScript` `WebExtensions MV3`

#### 🎲 [Deadlock Build Randomizer](https://github.com/lllexalllepexa/randomizer777) &nbsp;[*(Live Demo)*](https://lllexalllepexa.github.io/randomizer777/)
> Веб-рандомайзер сборок предметов для игры Deadlock.  
> `HTML5` `CSS3` `JavaScript`
